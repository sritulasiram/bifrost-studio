Native **Samsung Galaxy firmware flasher for macOS** — an **Odin alternative** for **Download Mode**: flash official `.tar.md5` packages (BL, AP, CP, CSC, HOME_CSC) over USB with offline plan review. Universal build (**macOS 13+**, Apple Silicon + Intel). **Ad-hoc signed** — if Gatekeeper blocks launch, **right-click → Open** once, then **Settings → Services → Register** and approve Login Items.

### Highlights
- Sidebar: **Flash**, **Inspect**, **History**, **Device**, **Android**
- Unlisted Download Mode PIDs; bootloader downgrade acknowledgement; SUPER/A-B warnings
- Flash presets, sidebar firmware drop, history failure clusters, Review plan JSON export
- Agent job journal; launch/window fixes; localization catalog
- App sources grouped under `App/`, `Model/`, `Bridge/`, `Workspace/`

### Install
1. Download **`BifrostStudio-1.1.0.dmg`** below → drag to **Applications**.
2. Register background services (see [README](https://github.com/sritulasiram/bifrost-studio#install)).

**Not Apple-notarized.** Flash only on hardware you can recover. Full changelog: [CHANGELOG.md](https://github.com/sritulasiram/bifrost-studio/blob/main/CHANGELOG.md#110---2026-11-15).
